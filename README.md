# GENESIS AI — Academic Event Invitation Website

A responsive, bilingual (English/Persian) multi-page website prototype for a fictional medical AI event.

## Pages
- `index.html` — Home
- `about.html` — About the concept
- `technology.html` — Technology overview
- `demo.html` — Prepared-response chat demo
- `countdown.html` — Countdown and live local clock
- `agenda.html` — Interactive agenda
- `team.html` — Fictional project team
- `invitation.html` — Invitation to Dr. Mohamad Poorarjmand
- `rsvp.html` — Front-end RSVP demonstration
- `venue.html` — Fictional venue and FAQ

## Run locally
Open `index.html` in a browser. For best results, use VS Code Live Server or another local static server.

## Features
- Separate HTML file for each page
- Shared responsive CSS and JavaScript
- English/Persian toggle with RTL support
- Dark/light theme saved in localStorage
- Countdown to 23 March 2027, 18:00 Europe/Berlin (CET, UTC+01:00)
- Live clock using the visitor's local timezone
- Prepared-response assistant (not connected to a real AI model)
- Interactive agenda, RSVP validation, and print-friendly invitation
- Responsive desktop, tablet, and mobile layouts

## Important
GENESIS AI, its team, event, and venue are fictional academic-project elements. The demo does not provide medical advice, diagnose conditions, analyze patient data, transmit RSVP responses, or store submissions on a server.
